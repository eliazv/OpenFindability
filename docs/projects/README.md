# Project reports

This folder contains dated analysis reports for projects inspected through OpenFindability.

Workflow:

1. Create one folder per project using a stable slug.
2. Save reports as `YYYY-MM-DD.md`.
3. Include data sources, date ranges, mismatches and operational priorities.
4. Do not include secrets, raw tokens or private credential contents.

Example:

```txt
docs/projects/eliazavatta-it/2026-05-25.md
```
